# 无边记 (Wubianji)

> 无限画布白板网页应用 — 纯原生 JS + Canvas 2D，零依赖。

打开 `index.html` 即可使用，无需构建、无需服务器。

---

## 🎨 功能

### 工具
| 快捷键 | 工具 | 说明 |
|---|---|---|
| `V` | 选择 | 单击选中、拖拽移动、8 点缩放、旋转、框选、Shift 多选 |
| `H` | 抓手 | 拖拽平移画布（空格按住临时切换） |
| `P` | 画笔 | 自由绘制，贝塞尔曲线平滑 |
| `R` | 矩形 | 拖拽创建，Shift 约束正方形 |
| `O` | 椭圆 | 拖拽创建，Shift 约束正圆 |
| `L` | 直线 | 拖拽创建，Shift 45° 角度吸附 |
| `A` | 箭头 | 同直线 + 箭头三角形 |
| `T` | 文本 | 点击放置，内联编辑，自动换行 |
| `N` | 便签 | 拖拽/点击创建，折叠角 + 阴影 |
| `E` | 橡皮擦 | 悬停高亮，点击/拖拽擦除 |
| `I` | 图片 | 插入图片，自动压缩（1200px JPEG 85%） |
| `B` | 表格 | 3×3 表格，双击编辑单元格，右键增删行列 |

### 操作
| 快捷键 | 功能 |
|---|---|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `Ctrl+C/V` | 复制 / 粘贴 |
| `Ctrl+G` | 编组 |
| `Ctrl+Shift+G` | 取消编组 |
| `Ctrl+A` | 全选 |
| `Ctrl+E` | 导出 PNG |
| `Ctrl+S` | 保存 JSON 文件 |
| `Ctrl+Shift+S` | 保存场景 |
| `Ctrl+[` / `Ctrl+]` | 上/下一个场景 |
| `Ctrl+Shift+P` | 演讲模式 |
| `Delete` | 删除选中元素 |

### 右键菜单
放到最上层/最底层 · 复制粘贴 · 编组/取消编组 · 锁定/解锁 · 表格增删行列 · 删除

### 样式
- **颜色**：填充色 + 描边色，各带独立 alpha 滑条，12 预设色
- **线宽**：1–20px 滑块
- **字号**：10–80px 滑块
- **对齐**：左/中/右 按钮
- **透明度**：填充和线条独立控制

### 场景 (Scenes)
保存画布视图为命名场景，一键跳转，带动画过渡，支持演讲模式。
- 场景栏在左下角，`▶` 按钮进入演讲模式
- 演讲模式隐藏 UI，方向键/点击切场景

### 表格
- 双击单元格编辑文字，自动换行
- 拖拽内部分隔线调整列宽/行高（总尺寸不变）
- 右键增删行列

### 其他
- 对齐参考线（拖动时显示红色辅助线）
- 尺寸面板（右下角，手动输入 W/H + 比例锁）
- 明暗主题切换（自动/亮色/暗色）
- localStorage 自动保存 + JSON 导入导出
- 触控支持（单指操作，双指缩放平移）

## 📁 文件结构

```
无边记/
├── index.html              # 入口
├── css/
│   └── style.css           # 全部样式
├── js/
│   ├── app.js              # 主应用、保存加载、场景、演讲模式、图片、表格
│   ├── camera.js           # 相机系统（平移/缩放/坐标转换）
│   ├── canvas-renderer.js  # Canvas 渲染（网格、元素、选中、参考线、表格、图片）
│   ├── elements.js         # 元素数据模型、CRUD、碰撞检测、编组
│   ├── history.js          # 撤销/重做命令栈
│   ├── tools.js            # 全部工具实现（选择/画笔/形状/文本/便签/橡皮擦/抓手/图片/表格）
│   └── ui.js               # 工具栏、颜色选择器、快捷键
└── README.md
```
